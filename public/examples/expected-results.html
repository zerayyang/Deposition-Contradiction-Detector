  2. Both texts should appear immediately. Each PDF has six questions and six answers.
  3. Analyze and compare the distinct issues below.
  4. Refresh and reopen the case: text, original-file links and findings should remain.

Target: four distinct conflicting issues and two compatible comparisons. Card counts can vary if compatible pairs are omitted. Do not duplicate the leaving-home conflict as another speaking or activity finding.

What about the confidence score?

No fixed numeric score is expected. The code may say “Not evaluable” when its supported rules cannot verify the comparison. That is different from saying the two accounts are compatible.

Failure checks

Scanned/blank pages should request OCR. Locked PDFs should request an unlocked copy. Oversized or invalid files should show an error. A failed import must keep the previous case contents.

All people and testimony are invented. The expected answers are separate from the AI prompt and production classification rules.
