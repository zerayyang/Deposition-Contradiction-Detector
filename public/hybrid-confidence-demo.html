What does this percentage mean?

With all three parts available: score = 60 × vote agreement + 30 × reviewer support + 10 × code support.

Reviewer support is 1 for agreement, 0.5 for agreement with concerns, or 0 for disagreement. Code support is 0 to 1 from deterministic rules. This simplified example uses full support or no support.

When no code rule applies, that part is unknown. Score = (vote points + reviewer points) ÷ 90 × 100. We do not invent code support.

Five of six votes, an agreeing reviewer, and full code support give 50 + 30 + 10 = 90%. Two of six votes, a dissenting reviewer, and no code rule give 20 ÷ 90 = 22%.

These weights are a chosen formula, not a fitted statistical calibrator. Training a calibrator needs independently human-approved examples and separate evaluation data. Human notes do not automatically add points. Old saved results retain their old weights.
