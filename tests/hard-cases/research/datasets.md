# Optional nonjudicial research examples: ContractNLI

20 examples from 20 distinct documents in the original test split: 8 Contradiction, 8 Entailment, 4 NotMentioned. Deterministic selection sorts document IDs and hypothesis IDs, chooses the first matching annotation in each unused document, then advances to the next requested label group. This is a convenience research sample, not a representative benchmark.

The hypothesis is unchanged. Both transcript fields now use a neutral Q: prompt followed by an actual newline and A: source text. Original document/hypothesis IDs, source URLs, original labels, evidence offsets, release archive hash, and original split remain in provenance. Neutral reconstructed Q/A prompts are added solely as input-format scaffolding, using actual newline separators. They do not assert real testimony or a witness identity. These are contract-to-hypothesis NLI examples. An Entailment supports a hypothesis; Contradiction refutes it under the dataset's document-level task; NotMentioned indicates insufficient information under that task. None is a judicial finding about two sworn statements. All proposed app labels are DEBATABLE and all application splits remain null. Original test split and annotations are separate metadata. They must not enter approved gold through an automatic mapping.

## Expected-results and execution guide

Expected research outcome: preserve all 20 original annotations and exact source strings. Expected application result: unresolved; no type, deterministic score band, truth finding, or accuracy target is authorized. Entailment rows provide possible compatible controls only after review; NotMentioned rows test missing context, not a proven falsehood. The evidence-envelope adaptation may omit definitions elsewhere in a contract; full document review is necessary.

For any authorized manual app trial, provide only transcript1 and transcript2; keep label, labelBasis, provenance, notes, originalTaskLabel, and this guide out of detector inputs. Use the coordinator's hard-case runner after explicit approval. No app run, paid call, gold append, or human approval occurred in this research operation.

DECODE was located through the official ParlAI project, but its dataset-specific license was not independently established in this bounded pass. No DECODE rows were imported. Stanford contradiction and other NLI data were not imported. This sample does not fill a court-testimony quota.

Format correction: all 40 transcript fields independently passed multiline Q/A line-anchor checks and exact equality of the entire source text following the A: separator. Quotes, original annotations, proposed labels, and split values were preserved; no app or runner was executed.

Source-format exclusion: `contractnli-test-225-nda-10` was removed because an embedded language heading could be mistaken for a named-speaker heading when adapting source text to Q/A input. It was replaced by `contractnli-test-47-nda-1`, from a different previously unused original-test document with the same original annotation (`NotMentioned`). Selection screened out short all-caps headings and leading name-like colon headings without changing source words. This is a format-only exclusion; no application classification or label feedback was consulted. The resulting sample still has 20 distinct documents and the 8/8/4 original-label distribution.
